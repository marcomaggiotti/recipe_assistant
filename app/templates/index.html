Pizza Service

Dough formulas for pizza and bread - a flour blend and an optional pre-ferment, turned into ingredient weights and a schedule - plus a topping menu to compose a pizza from.

🍞

New Recipe

Build a bread or pizza dough formula from a flour blend and save it.
🌾

Flour Explorer

Browse the international flour catalogue - filter by category, ash%, type code, or strength.
🔗

Add Flour Product

Link a real product page (Migros, Coop, ...) to the flour_catalog entry it actually is.
🫓

Pre-ferments

Save a reusable named pre-ferment blend (e.g. biga 60% / poolish 40%) a recipe can reference.
📋

Recipes

Browse saved recipes and see any one's fermentation schedule as a pipeline.
🍕

Compose Pizza

Pick toppings from the menu, including composite ones like pesto or ricotta with lemon zest.
🧀

Toppings

Add toppings to the pizzeria menu - plain ingredients or composite ones made from their own recipe.
📄

API Docs

This service's own REST API (recipes, pre-ferment types, agent chat) - interactive Swagger UI.
Flour catalogue and product-link data are served live from flour-service; the topping menu from topping-service.
